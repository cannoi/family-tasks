# Family Tasks Installation Guide

## Prerequisites

- Docker
- Docker Compose

## Installation Steps

1. Clone the repository
2. Navigate to the project directory
3. Run `docker-compose up -d`

## Accessing the Application

Open your browser and navigate to `http://localhost:18080`

## Configuration

Edit the `config_options.yml` file to configure the application settings.

## Troubleshooting

If you encounter any issues, please refer to the [README](README.md) or open an issue on GitHub.
