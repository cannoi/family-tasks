# Family Tasks

Family Tasks là một ứng dụng đơn giản để phân chia công việc gia đình, giao nhiệm vụ, đặt hạn và theo dõi hoàn thành.

## Features

- Phân chia công việc gia đình
- Giao nhiệm vụ
- Đặt hạn
- Theo dõi hoàn thành
- Thông báo nhắc nhở
- Báo cáo tiến độ
- Chia sẻ nhiệm vụ với bạn bè

## Installation

1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Usage

1. Register a new user
2. Login with your credentials
3. Create or join a family
4. Create tasks and assign them to family members
5. Mark tasks as completed
6. View notifications and task progress
